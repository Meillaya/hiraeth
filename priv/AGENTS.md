# PRIV DATA KNOWLEDGE BASE

## OVERVIEW
Runtime data, source evidence, migrations, static assets, provider manifests, source snapshots, and the canonical cover cache. Treat checked-in corpus and snapshots as governed evidence.

## STRUCTURE
| Area | Owns |
|---|---|
| `catalog_sources/provider_manifests/` | provider fetch/source/caching policy manifests |
| `catalog_sources/real_publishers/` | checked-in publisher corpus + authority/artifact/coverage manifests |
| `catalog_sources/staged/` | transient staging area: created by `mix hiraeth.scrape`, removed after apply; absence is normal |
| `source_snapshots/` | runtime retention root for raw provider payload artifacts (only `.gitkeep` checked in; `source-snapshots/` subtree is gitignored runtime data) |
| `resource_snapshots/repo/` | Ash generator state (diff baseline for `ash_postgres` generators) — not replay data |
| `static/covers/cache/` | canonical local public cover cache |
| `repo/migrations/` | database migrations generated by Mix |
| `repo/structure.sql` | gitignored, untracked local pg_dump artifact — not governed; do not commit without explicit intent |

## CONVENTIONS
- Provider manifests and real-publisher records are source-of-truth inputs, not scratch fixtures.
- Preserve source provenance so every value can trace to provider, source record, and import run.
- Source snapshots are immutable evidence for replay/audit. Add new snapshots; do not rewrite old evidence casually.
- Public covers must resolve to local `/covers/cache/...` or fallback typography; remote cover URLs are not public UI assets.
- Migrations must be generated with `mix ecto.gen.migration migration_name_using_underscores`.
- Large generated runtime state belongs in ignored artifacts/caches unless it is a deliberate checked-in source snapshot/corpus update.

## ANTI-PATTERNS
- Removing a publisher/provider manifest, source snapshot, real-publisher dataset, source-authority record, or staged governance artifact without explicit authorization for that publisher.
- Cleaning, truncating, moving, regenerating, or blanket-formatting `priv/static/covers/cache/*`.
- Editing coverage/authority/artifact manifests by hand without running or documenting the generator path.
- Adding remote image URLs to public static references in place of cache entries.
- Mixing one-off operator scratch files into governed source directories.
